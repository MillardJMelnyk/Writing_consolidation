# Writing_consolidation

Millard J Melnyk's writing and notes from every source, gathered in one place and catalogued so that all of it can be found and searched.

## What's in this repository

- **[Master catalog](catalog/Master_catalog.md)** — the catalog of all the work: a list of every item (by date or by title), an A–Z index of subjects, names and terms, and a topic outline. **[How to use the catalog](catalog/How_to_use_the_catalog.md)**.
- **Substack profile PDFs** (top level) — everything listed on substack.com/@millardjmelnyk as of 2026-11-01, newest first, in two searchable PDFs with images:
  - Substack_millardjmelnyk_profile_part1_of_2_2026-11-01_to_2025-08-19.pdf
  - Substack_millardjmelnyk_profile_part2_of_2_2025-08-19_to_2022-07-31.pdf
- **catalog/** — the catalog pages, one page per item with its full text, the data lists, and the tools that build the catalog.

Related repository: **AI_Chats** (MillardJMelnyk/AI_Chats) holds the archived Claude chats from both accounts; the catalog links to them.

## Rules and guidelines

- The goal is a searchable repository of all the work, regardless of source.
- Every discrete item (note, post, chat, page, file) gets its own catalog page with its full text and a link to the original.
- Items are filed under every topic subheading that fits (up to 9) and get 3–8 index terms.
- Topic headings describe content, never the type of item.
- Every list is shown both by date and by title.
- Coding chats are left out for now; empty chats are dropped; empty Substack notes are kept.
- Files are kept at the top level unless they belong to the catalog.
- Work that will be reused (scripts, instructions, working data) is saved in this repository, in catalog/tools.
