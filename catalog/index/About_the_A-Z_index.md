# About the A–Z index

[← Master catalog](../Master_catalog.md)

The A–Z index works like the index at the back of a book. Each entry is a subject, name or term that appears in the catalog's items: people, organizations, places, books, laws, events and concepts. Every item has 3 to 8 entries, so one item appears under several entries.

## How it is organized

- **Letter pages:** one page per letter, listing every entry that starts with that letter, with the number of items for each in brackets.
- **Entry pages:** one page per entry, listing every item it appears in. Each list is shown twice: by date and by title.

The start page, [A–Z index](A-Z_index.md), links to every letter.

## How to use it

1. Open [A–Z index](A-Z_index.md) and click a letter.
2. Find the entry you want and click it.
3. Use **by date** or **by title** at the top of the list to jump to the order you want.
4. Click any title to open the item.
