### Claude · 2026-08-15 01:55

Common ones:

**Cheats** (need `sv_cheats 1` first — auto-allowed on servers ≤3 players, or LAN):  
- `god` / `godmode` — invincibility  
- `cl_noclip` / `noclip` — fly through walls  
- `notarget` — enemies ignore you  
- `give <item_classname>` — give a weapon/item/ammo  
- `giveall` — all weapons + infinite ammo  
- `impulse 101` — all weapons, some ammo, battery  
- `impulse 100` — flashlight toggle  
- `healme` / `chargeme` — full health / full HEV charge  
- `gibme` — gib yourself  
- `noclip`, `notarget`, `god` toggle with 0/1 args, e.g. `god 1`

**Non-cheat / general:**  
- `bind <key> <command>` — key bind  
- `sv_cheats <0-3 or 255>` — cheat access level  
- `sensitivity <value>` — mouse sensitivity  
- `fps_max <value>` — FPS cap  
- `cl_showfps 1` — FPS counter  
- `record <demoname>` / `stop` — demo recording  
- `map <mapname>` — load a map  
- `maxplayers <n>` — server slot count  
- `say` / `say_team` — chat

Full alphabetical reference: https://developer.valvesoftware.com/wiki/List\_of\_Sven\_Co-op\_console\_commands\_and\_variables

### Claude · 2026-08-15 02:49

No native console command. `giveall` gives infinite ammo for those weapons, or repeated `give ammo_x` calls. True per-weapon infinite ammo requires the third-party wootguy Cheats plugin (`.infammo`) — not stock.
