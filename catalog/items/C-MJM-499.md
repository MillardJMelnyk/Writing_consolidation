### Claude · 2025-12-21 14:02

I need to search for current information about this X Chat requirement, as this appears to be a recent platform change.

X rolled out a mandatory upgrade to their direct messaging system called "X Chat" in mid-November 2025 (November 13-16, 2025). This new system requires all users to complete setup—including creating a passcode/PIN—before they can share posts via direct message.

**Why the requirement exists:**

* X Chat implements end-to-end encryption for messages
* The setup creates a public-private key pair for each user
* The PIN secures your private key on X's infrastructure
* Sharing posts via DM now routes through this encrypted chat system

**Key limitation:**
You cannot share posts to other users via direct message until you complete the X Chat setup. Other sharing options (WhatsApp, Signal, Telegram, copy link) remain available without X Chat setup.

This change was rolled out to all users in November 2025 as part of Musk's "everything app" vision for X, though it proved controversial due to the mandatory passcode requirement and removal of some previous DM features.
