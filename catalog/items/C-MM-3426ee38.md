how do i turn my network to public network so it is safer?

### Claude · 2026-09-08 00:13

Windows 11: Settings → Network & internet → click your connection (Wi-Fi or Ethernet) → click the network name/properties → under Network profile type, select **Public network**.

Windows 10: Settings → Network & Internet → Wi-Fi or Ethernet → click the network name → select **Public**.

Fastest path either way: Win+I, type "network profile" in the search box.
