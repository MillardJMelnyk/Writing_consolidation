### Claude · 2026-07-28 16:13

Yes — it's the platform's default chart background/branding, not an indicator. In cTrader: Chart menu → Chart Properties (or right-click chart → Properties) → find the "Show branding/background logo" option and disable it. If that option isn't there, check View → Preferences → Charts for a "Watermark" or "Logo" toggle.
