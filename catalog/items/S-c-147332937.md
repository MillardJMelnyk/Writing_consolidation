As good as this might sound, it's symptom management, not cure.

Would emotional education change the world for the better? Yes, somewhat.

But this is another tail-wag-dog approach, as shallow as any, that ignores causes and targets effects.

Emotional regulation in a world where you're continually being violated is not the same as emotional regulation in a world where you're safe.

Emotional regulation while you remain codependent is not the same as emotional regulation when you're fully human.

Infantilism that creates codependence is the basic effect.

A world that mind-fucks you into captivity in infantilistic codependence, so that it can dehumanize, abuse, extort, exploit you, sucking your soul dry, is the cause.

And no one, so far, has any confidence or faith that we can fix the cause.

Because they're codependents.
