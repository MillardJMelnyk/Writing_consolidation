Not a scam. Here's what's actually happening:

**The URL is legitimate.** The domain is `capcut.com` — CapCut's own domain. The `fission_receive` path is CapCut's internal referral/invite system, used widely and documented across third-party referral sites.

**How it works.** The referral code (`IvaCUg16444773`) is embedded in the URL itself. Clicking that link before or during installation is supposed to register the referral automatically — you don't manually type the code anywhere. The "enter the invitation code" instruction in the page copy is either outdated or refers to a flow that only appears during new account creation on some versions.

**Two caveats:**

1. The current reward may be storage space (45 days of bonus storage), not 7 days of Pro. CapCut has changed its referral rewards over time and the page copy may not reflect the current offer. (As of late 2024/early 2025 reporting, it's storage-based, not Pro access.)
2. CapCut is made by ByteDance (TikTok's parent company). Some users in certain countries have concerns about data privacy for that reason. That's a separate judgment call from scam/not-scam.

**Bottom line:** The link is what it claims to be — your granddaughter's CapCut referral link. The vague instructions are a CapCut documentation problem, not a red flag.
