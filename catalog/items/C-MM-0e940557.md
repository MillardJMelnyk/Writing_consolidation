For book editing (use case #2), don't go local. Use a cloud model — Claude, GPT, whatever — through the same AnythingLLM interface if you want, or directly. AnythingLLM supports cloud LLM providers alongside local ones, so you can point your "Research" workspace at Ollama and your "Editing" workspace at an API. The editorial quality difference is not subtle; it's the difference between useful and not useful for the kind of feedback that actually improves a manuscript.

If you want to upgrade the hardware side later, the single most impactful change would be swapping the 2060 Super for a used RTX 3090 (24GB VRAM). That opens up 13B–30B models at decent speed, which is where local models start becoming genuinely useful for writing.
