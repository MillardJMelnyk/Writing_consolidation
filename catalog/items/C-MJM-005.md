### Millard · 2025-05-28 12:58

On your download page it has an option for the Windows desktop app but it also has an option for windows (arm64). What's arm64?

### Claude · 2025-05-28 12:59

ARM64 refers to a specific type of processor architecture. Here's the difference:

**Regular Windows version**: Designed for traditional Intel and AMD processors (x86/x64 architecture) that you'll find in most desktop computers and laptops.

**Windows (ARM64) version**: Designed for ARM-based processors, which are increasingly common in newer devices like:

* Microsoft Surface Pro X and some Surface Laptop models
* Certain Windows laptops with Qualcomm Snapdragon processors
* Some newer thin-and-light laptops that prioritize battery life

ARM processors were originally designed for mobile devices (phones, tablets) and are known for being more power-efficient. They're now making their way into laptops and desktops, similar to how Apple transitioned their Macs to ARM-based M1/M2/M3 chips.

If you're not sure which version you need, you most likely want the regular Windows version. You can check your processor type by going to Settings > System > About in Windows - if it mentions ARM or Qualcomm, you'd want the ARM64 version. Otherwise, stick with the standard Windows download.
