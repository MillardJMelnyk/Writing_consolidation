### Claude · 2026-07-31 00:12

Thursday, July 30, 2026

Luke 10:41-42 has a genuine textual variant behind this. The Greek manuscripts split between a shorter reading ("one thing is necessary") and a longer reading ("few things are necessary — or only one"). Translations follow one or the other, sometimes footnoting the alternative.

**Main text reads "few things... or only one":**

* NIV (1984, 2011): "few things are needed—or indeed only one"
* NET Bible: "few things are needed—or in fact only one"

**Main text reads "one thing" only, but footnotes the "few things" variant:**

* RSV: main "one thing is needful"; footnote gives the longer variant
* NRSV: main "there is need of only one thing"; footnote gives the longer variant
* CSB: main "only one thing is necessary"; footnote gives the longer variant
* NASB (1995/2020): "only one thing is necessary" — no variant footnote

**"One thing" only, no variant noted:**

* KJV/NKJV: "one thing is needful"
* ESV: "one thing is necessary"
* NLT: "there is only one thing worth being concerned about"

If you want the manuscript-level detail (which uncials/papyri support which reading), that's a separate question — ask if you want it.
