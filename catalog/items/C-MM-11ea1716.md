how do I get the win 11 snipping tool to automatically take a full screen print?

### Claude · 2026-09-11 20:57

Set Snipping Tool's mode dropdown to **Full screen** — it keeps that mode, so the next trigger captures the whole screen with no dragging.

Two ways to trigger it:  
- **PrtScn** — turn on Settings → Accessibility → Keyboard → "Use the Print screen key to open screen capture"  
- **Win + Shift + S** — same thing, no settings change needed

If you want it saved to a file automatically with no Snipping Tool window at all, use **Win + PrtScn** — it drops a PNG straight into Pictures\Screenshots.

That's the key — usually labeled PrtScn, PrtSc, or Print Scr, top-right row near F12.

### Claude · 2026-09-11 21:00

Your MX Keys S has no PrtScn key — it has a **camera key** above the numpad, where PrtScn used to sit. By default it opens the Snipping Tool overlay, which is what you're fighting.

To get full-screen-to-file with one press:

1. **Logi Options+** → your keyboard → click the camera key → set it to **Keyboard shortcut**, not "Screen capture." Problem: recording a shortcut requires pressing a real PrtScn key, which you don't have.
2. So use **PowerToys Keyboard Manager** instead: remap any key you don't use (Scroll Lock, right Ctrl, numpad /) to **Print Screen**. Then Win + that key saves a full-screen PNG to Pictures\Screenshots.
3. Turn **off** Settings → Accessibility → Keyboard → "Use the Print screen key to open screen capture" — otherwise Windows hijacks the keycode back to the Snipping Tool.

The camera-icon key top-right, directly above the numpad.
